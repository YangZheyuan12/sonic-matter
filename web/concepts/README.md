# Sonic / Matter 高保真概念稿

- `home.html`：首页创作驾驶舱，保留原有声场球、深色青紫视觉和双入口。
- `game-brief.html`：游戏简报，使用阶段进度、结构化表单、实时摘要与 Agent 建议。
- `sound-direction.html`：声音方向，以情绪、节奏、质感和声音指纹建立跨音乐/音效的统一创作约束。
- `music-studio.html`：三栏式音乐工作室，突出轨道、编排、钢琴卷帘和 Agent Inspector。
- `sfx-lab.html`：音效实验室，整合素材库、波形版本、结构化声音计划与语义混音器。
- `my-settings.html`：我的工作区与设置，集中展示工程、外观、服务、存储和创作偏好。
- `rendered/`：1440 × 1000 的最终概念截图。

概念页面仅用于设计确认，不接入生产导航。确认后再按页面拆分为 React 组件。
